# Quiz App Vergara

A frontend quiz made with React, TypeScript, Vite, and React Router. The existing design, colors, fonts, icons, and quiz flow are kept as they were.

## Run the project

1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown in the terminal.

## Check before deployment

- Run `npm run typecheck` to check TypeScript types.
- Run `npm run build` to create the production build in `dist`.

## Main features

- Ten frontend development questions
- Select answers and move between questions
- Progress display and score summary
- Retake quiz and return home
